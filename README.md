# Sentiment Analyzer

Простой классификатор тональности текста (позитив/негатив) на Python.
Проект для практики NLP: предобработка текста, TF-IDF, логистическая регрессия.

## Как это работает

1. **Предобработка** (`src/preprocess.py`) — чистим текст: нижний регистр,
   убираем пунктуацию и цифры.
2. **Обучение** (`src/train.py`) — превращаем текст в числа через TF-IDF,
   обучаем `LogisticRegression`, сохраняем модель.
3. **Предсказание** (`src/predict.py`) — загружаем обученную модель
   и предсказываем тональность нового текста.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

Обучить модель:

```bash
cd src
python train.py
```

Предсказать тональность нового текста:

```bash
python predict.py "Отличный сервис, всё понравилось"
# -> Тональность: positive
```

Запустить тесты:

```bash
pytest tests/
```

## Датасет

`data/reviews.csv` — небольшой учебный датасет (40 отзывов на русском).
Для реального использования стоит заменить на датасет побольше,
например с [Kaggle](https://www.kaggle.com/datasets) (поиск: "russian reviews sentiment").

## Что можно улучшить дальше

- Добавить лемматизацию (например, через `pymorphy2`) — сейчас слова
  вроде "покупал" и "покупать" считаются разными
- Убрать стоп-слова (предлоги, союзы)
- Попробовать другие модели: `SVM`, `RandomForest`, `Naive Bayes`
- Расширить датасет — на 40 примерах модель переобучается
